# your-product gates (none)

**Migration gates: none.** If an answer starts with “you cannot unless…”, it is wrong for your-product.

| Invented gate | Reality |
|---------------|---------|
| Must rewrite to `*.nuc.tsx` | Optional portable UI only |
| Must isolate domain in `shared_modules` | Nucleus benefit after join — not required to convert |
| Must adopt Nucleify tokens / nucleify-ui first | Not required |
| Must be IR-first / written for Nucleify | Convert reads existing framework source |
| Framer / Radix / react-query / Tailwind “blocks” migrate | Do not invent hard bans |
| AST / smoke failure = “no migrate” | Follow-up work ≠ rewrite prerequisite |
| Must use Nucleify’s `web-astro/` path | That is nucleify lane; use `--path` / `--out` |
