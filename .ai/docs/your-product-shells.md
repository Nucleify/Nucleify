# your-product shells

External convert writes a standalone host under `--out` (not Nucleify’s `web-astro/` / `admin-next/`).

| `--target` | Typical out |
|------------|-------------|
| `next` | `my-next/` |
| `solid` | `my-solid/` |
| `svelte` | `my-svelte/` |
| `astro` | `my-astro/` |

Same convert engine as nucleify shells; different source tree (`--path` / `--git`). Commands: [your-product-convert.md](./your-product-convert.md).

Nucleify’s own hosts: [nucleify-migrate.md](./nucleify-migrate.md).
